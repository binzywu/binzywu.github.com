02 · Explore saturation and competitive inhibition

This illustrative rate model holds Vmax=100 rate units and uses v=Vmax·S/(αKm+S), where α≥1 represents competitive inhibition. The model is a quantitative extension, not an equation you must memorize for this toolkit’s AP-topic checks. It does not simulate pH, temperature or all inhibitor mechanisms.

Green: selected α · dashed orange: no inhibitor, α=1 · gray: Vmax. Substrate and Km use matching arbitrary concentration units.

Choose two diploid parent genotypes. The grid combines gamete draws, assuming equal segregation, random fertilization and equal viability. A is completely dominant to a for the phenotype summary. These predictions are probabilities, not guaranteed counts in a small family.

04 · Compare a null model with selection

Set allele frequency p, then change relative survival/reproductive contributions for AA,Aa and aa. The model starts with Hardy–Weinberg genotype frequencies, applies one generation of viability selection and computes p among survivors. It omits drift, migration and new mutation. Survivor genotypes need not remain in Hardy–Weinberg proportions.

Green: before selection · orange: normalized surviving genotypes. A label is an allele name, not a statement of fitness or dominance.

05 · Compare exponential and logistic growth

These continuous deterministic models start from N₀=20 with a constant per-capita parameter r. The logistic model also uses a fixed carrying capacity K. Real populations can have delays, stochasticity and changing resources; these curves are model predictions.

Green: logistic · dashed orange: exponential · gray: carrying capacity. A shared vertical scale can compress the logistic curve when exponential values are large.
