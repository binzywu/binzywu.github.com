Short-run AD–AS changes

A normalized illustrative model: AD price = 140 + demand shift − 0.5Y; SRAS price = 40 + cost shock + 0.5Y. Potential output is fixed at 100. This is a short-run comparison; the controls do not model wage adjustment, expectations or long-run growth.

A useful study session

  1. Recall one idea from the previous unit.
  2. Predict the next worked step before revealing it.
  3. Rebuild the example on paper with labeled units or graph axes.
  4. Complete both checks. The lesson list retains ✓ Completed.
  5. Vary one model input and explain the result, then try the unit’s written drill.

Completed checks record practice, not mastery or an AP score.

Read a model carefully

  1. State the question and time horizon.
  2. Label axes and distinguish a stock, flow, rate and percentage.
  3. Identify what is held fixed.
  4. Explain each causal link or mathematical step.
  5. Identify a limitation and evidence that could test the claim.
